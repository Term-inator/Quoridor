# Triage 标签

工程技能使用五种规范化 triage 角色。下表把这些角色映射到本仓库实际使用的标签字符串。

| 技能中的标签 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可以交给 agent 实现 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会处理 |

当技能提及某个规范化角色时，使用上表对应的本仓库标签。需要适配既有标签体系时，直接修改右侧一列。
